Currency Converter

Currency Converter is a simple Java application that converts different currencies into Indian Rupees (INR) using predefined exchange rates. The application provides a user-friendly console interface for quick and easy currency conversion.

Features

- Convert USD (United States Dollar) to INR
- Convert EUR (Euro) to INR
- Convert GBP (British Pound) to INR
- Simple console-based interface
- Fast and accurate calculations

Technologie Used

- Java
Concepts Used

- Scanner Class
- Switch Case
- User Input Handling
- Arithmetic Operations

Supported Currencies

- USD - United States Dollar
- EUR - Euro
- GBP - British Pound
- INR - Indian Rupee

Sample Output

=== Currency Converter ===

1. USD to INR

2. EUR to INR

3. GBP to INR

Enter amount: 100
